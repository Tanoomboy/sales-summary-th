# ข้อมูลตัวอย่าง (example data)

ไฟล์ในโฟลเดอร์นี้เป็น **ข้อมูลตัวอย่าง** ตัวเลขสมมติทั้งหมด ชื่อคน เบอร์โทร และเลขบัญชีเป็นของปลอม

- `ข้อมูลตัวอย่าง-ยอดขาย.csv` ร้านเครื่องดื่ม 2 วัน (เมื่อวาน + วันนี้) ใช้ลองคำสั่งได้เลย
- `ข้อมูลตัวอย่าง-มีข้อมูลส่วนตัว.csv` ไว้ลองดูว่าโปรแกรมตัด/ปิดบังข้อมูลส่วนตัวอย่างไร
- `make_sample.py` สคริปต์ที่ใช้สร้างไฟล์ยอดขายตัวอย่าง
